## 見るときの注意

- **仮のデータで動いています。** ゴルフ場・地域名はすべて架空（名前の頭に「(仮)」）、利用者も架空の5人です
- **本物のデータベースにはつながっていません。** ページを再読み込みすると、入力したものは消えて最初の状態に戻ります
- 通報・ブロック・課金はまだありません。**人には配らないでください**

ここにあるのは**ブラウザ用に書き出した画面だけ**です。中身のコードは別の非公開リポジトリ（`golf-round-app`）にあります。
